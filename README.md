# Multi-Platform Search Assistant 

A simple desktop application built with Python and Tkinter that allows users to search Google, YouTube, and Instagram from one interface.

## Features

- Search YouTube directly from the application
- Search Google
- Open Instagram profiles
- Input validation for empty searches
- URL encoding for search queries
- Clear the search field
- Press Enter to search on Google
- Simple desktop GUI built with Tkinter

## Technologies Used

- Python
- Tkinter
- Webbrowser
- urllib.parse

## How It Works

The user enters a search query in the input field and chooses a platform.

- **YouTube** opens YouTube search results
- **Google** opens Google search results
- **Instagram** opens the entered Instagram profile
- **Clear** removes the current text from the input field
